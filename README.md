# Charity Mobile Application

## Project Description
The **Charity Mobile Application** is a React Native mobile application built using **Expo** and **Expo Router**.  
The application provides a platform where users can interact with charity-related features through a mobile interface.

The project uses modern **React Native libraries**, **Expo tools**, and **TypeScript** to create a scalable and maintainable application.

---

# Technologies Used

- React Native
- Expo
- Expo Router
- TypeScript
- React Navigation
- Vector Icons
- ESLint

---

# Project Setup

## 1. Clone the Repository

```bash
git clone https://github.com/Ntombenhle2004/charity-react-native-ui.git
```

---

## 2. Navigate to the Project Folder

```bash
cd charity
```

---

## 3. Install Dependencies

```bash
npm install
```
---

# Running the Application

## Start the Expo Development Server

```bash
npm start
```

This will start the Expo development server.
